# Goal Rush 3D

Playable Unity 6 LTS-style Android portrait football obstacle runner MVP.

## Features
- 3-lane auto runner
- Swipe/touch lane switching, jump and slide
- Coins, money, gems and health
- Green reward / red penalty gates
- Rotating bars, spikes, moving blocks and ramps
- Shield, magnet, speed boost, 2x money and super jump
- 5 worlds and 100 deterministic levels
- Shop, missions, daily rewards
- Pause, level complete and game over flows
- Versioned JSON local save
- Runtime-generated UI and placeholder 3D assets
- Android portrait configuration

## Open
Open the project in Unity 6 LTS using Assets/Scenes/Bootstrap.unity.

## Controls
Swipe left/right: lane. Swipe up: jump. Swipe down: slide.
Editor: A/D or arrows, Space jump, S/down slide.

## Build Android
Set Android platform in Build Profiles, Portrait orientation, package identifier com.goalrush3d.game, then build APK/AAB.

## Source package
The initial Unity source package is supplied alongside this repository as GoalRush3D_Unity_Project.zip.

## Notes
The game uses an original fictional football character and runtime-generated primitives rather than real-player likenesses or club branding.
